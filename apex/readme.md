# Oracle APEX

Esta pasta contém a exportação da aplicação **Algomed** desenvolvida no Oracle APEX.

O arquivo `.sql` permite recriar a aplicação em outro ambiente APEX compatível.

## Aplicação

- Nome: Algomed
- Plataforma: Oracle APEX
- Banco: Oracle Autonomous Database
- Funcionalidades principais:
  - Dashboard com indicadores de saúde
  - Gráficos por Região de Saúde
  - Assistente "Pergunte ao Algomed"
  - Integração com Oracle Select AI e Google Gemini
