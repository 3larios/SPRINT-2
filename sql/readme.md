# Scripts SQL

Esta pasta reúne os principais scripts SQL utilizados no desenvolvimento do Algomed.

## Conteúdo

- Criação e configuração de objetos do banco
- Grants e permissões
- Views analíticas
- Consultas utilizadas nos cards e gráficos do dashboard
- Scripts relacionados ao Oracle Select AI

Os scripts foram executados no Oracle Autonomous Database por meio do Oracle Database Actions / SQL Worksheet.

## Objetivo

Os arquivos desta pasta documentam a camada de tratamento, consolidação e consulta dos dados utilizados pelo MVP do Algomed.
